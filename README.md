# VoltFinder - Electric Vehicle Charging Finder

VoltFinder is a web application that helps users find nearby electric vehicle (EV) charging stations. The app provides real-time location data for EV charging points, helping users locate the nearest stations.

You can visit the project repository on [Weblink to Voltfinder](https://volt-finder-frontend.vercel.app/register) for live site.

## Features
- **Real-time EV charging station data**: Find nearby EV charging stations with the help of Google Maps API.
- **User login**: Users can create an account and log in to save their preferred locations.
- **Location-based service**: The app shows charging stations based on the user’s location.
- **Registration and login**: Simple registration using name, username, email, and vehicle details.

## Installation
To install and run the project locally, follow these steps:

1. Clone and Install the required dependencies:
    ```bash
    cd VoltFinder
    npm install
    ```

3. Set up your environment variables (for Google Maps API and other services).

4. Run the application:
    ```bash
    npm start
    ```

## Technologies Used
- **Frontend**: React.js
- **Backend**: Node.js
- **Database**: MongoDB (Cloud-hosted)
- **API**: Google Maps API for charging station location data
